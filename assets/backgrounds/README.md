# Default backgrounds

Every image here ships with the app and appears in the Stage tab's background picker on
first start. Adding one is the whole job: drop the file in and rebuild the package. See
[Default backgrounds](../../README.md#default-backgrounds) in the main README for the
rules — the short version:

- `.jpg` `.png` `.webp` `.gif` for stills; `.mp4` `.webm` `.mov` for a looping motion
  background. Lower-case extensions.
- The filename becomes the title the operator sees (`mountain-lake-reflection.jpg` →
  "Mountain Lake Reflection") **and** the background's permanent id. Name it well the first
  time; renaming a file that has already shipped gives existing installs a duplicate.
- 1920×1080 or larger, landscape, where possible.

This README is not shipped — the build only picks up the file types above.
