## Teardown

Run only after Windows dev is verified and you no longer need the environment.

```powershell
# 1. repo-local artifacts (safe, regenerable)
Set-Location C:\Users\DELL\Desktop\LumosPresenter
Remove-Item -Recurse -Force `
  frontend\node_modules, `
  src\LumosPresenter.WebHost\wwwroot, `
  src\LumosPresenter.WebHost\models, `
  src\LumosPresenter.WebHost\data, `
  src\LumosPresenter.WebHost\media, `
  src\LumosPresenter.WebHost\logs -ErrorAction SilentlyContinue
Get-ChildItem -Recurse -Directory -Include bin,obj | Remove-Item -Recurse -Force
New-Item -ItemType Directory -Force src\LumosPresenter.WebHost\wwwroot | Out-Null
New-Item -ItemType File src\LumosPresenter.WebHost\wwwroot\.gitkeep | Out-Null

# 2. dotnet side effects (do BEFORE uninstalling the SDK — needs the dotnet CLI)
dotnet dev-certs https --clean
dotnet nuget locals all --clear

# 3. the toolchain itself
winget uninstall --id Microsoft.DotNet.SDK.10 --exact
winget uninstall --id OpenJS.NodeJS.LTS --exact
```

Order matters: step 2 uses the `dotnet` CLI, so it must run before step 3 removes it.

Leave alone: `Program Files\Microsoft.NET` (legacy .NET Framework, part of Windows),
`git`, `winget`.
